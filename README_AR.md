# تطبيق سمراء الكبودي — مدرسة اليتمة

هذه نسخة بداية لمشروع Android Studio بلغة Kotlin بواجهة عربية RTL، وألوان أزرق/ذهبي، مع تهيئة Firebase Authentication وCloud Firestore.

## مهم
- هذا **مشروع مصدر أولي** وليس APK جاهزاً للتثبيت أو منشوراً على Google Play.
- يلزم تثبيت Android Studio وJDK المناسب، وإنشاء مشروع Firebase وربطه قبل تشغيل قاعدة البيانات.
- لا تضع كلمات المرور أو مفاتيح الإدارة في الكود.
- لا تدخل أسماء الطلاب أو درجاتهم الحقيقية قبل إعداد الصلاحيات والخصوصية وموافقة المدرسة.

## الإعداد
1. افتح Firebase Console وأنشئ مشروعاً باسم `samra-al-yatmah`.
2. أضف تطبيق Android بالمعرّف `com.samraalyatmah.app`.
3. نزّل `google-services.json` وضعه في مجلد `app/`.
4. فعّل Email/Password في Firebase Authentication وأنشئ حساب المديرة من Firebase Console.
5. أنشئ Cloud Firestore، وطبّق قواعد الأمان الموجودة في `firestore.rules`.
6. افتح المجلد في Android Studio، ثم Sync Gradle وشغّل التطبيق على محاكي أو جهاز.
7. قبل النشر: أضف سياسة خصوصية ورابطها، واختبر صلاحيات الحسابات وبيانات الطلاب.

## الحسابات والصلاحيات
- لا يوجد حساب مدير افتراضي أو كلمة مرور مضمّنة.
- يجب إنشاء حساب المديرة يدوياً، ثم إضافة مستند `users/{uid}` في Firestore بحقل `role: "admin"` من بيئة موثوقة.
- لا تمنح الدور الإداري من التطبيق العام؛ يجب أن يقتصر ذلك على مسؤول موثوق.

- صفحة رئيسية عربية.
- عرض أسماء الطلاب والطالبات.
- نموذج تسجيل طالب جديد.
- عرض نتائج الاختبارات.
